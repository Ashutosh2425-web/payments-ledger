# Payments Ledger

A reliable payment ledger system built with Node.js, Express.js, PostgreSQL, React, and Docker.

## Tech Stack

- Node.js
- Express.js
- JavaScript
- PostgreSQL
- React
- Docker
- Jest
- Supertest

## Project Status

 Under Development

## Goal

Build a production-style payment ledger focusing on:

- Double-entry accounting
- Transaction safety
- Concurrency control
- Idempotency
- Refunds and reversals
- Webhooks
- Reconciliation
- Automated testing
